Six side-by-side Duo backgrounds, generated with the built-in image_gen tool. Exact prompts and source hashes are in generation.json.

Mapping: window = Mochi; study = Pip; river = Pebble; cafe = Jun/Bean/Maple; academy = Luna/Atlas/Wisp; orbit = Nova/Orbit/Comet.

These are background-only 1536x1024 images. Characters, speech, controls and spin transitions remain native layers. The right half stays quiet for the timer. DuoLandscapeBackdrop places the original upper 80% into the top 70% of the canvas and stretches the floor below it so the existing platform-layout character positions stand within the floor area. The old CylinderBackdrop is disabled only for the side-by-side Duo layout. Portrait seated scenes and other devices keep their existing artwork.
