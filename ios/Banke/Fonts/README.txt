Manrope Bold — offline clock typography

Source: https://github.com/google/fonts/tree/main/ofl/manrope
Upstream file: Manrope[wght].ttf
License: SIL Open Font License 1.1; see OFL-Manrope.txt alongside this file.

Manrope-Bold.ttf is the upstream variable font instantiated at wght=700
with fontTools.varLib.instancer.instantiateVariableFont(updateFontNames=True).
Its PostScript name is Manrope-Bold. This matches the web timer's
Manrope / font-weight: 700, without a runtime font download.

Banke/Info.plist registers Fonts/Manrope-Bold.ttf through UIAppFonts.
Scripts/make_project.py copies this folder into the application bundle.
